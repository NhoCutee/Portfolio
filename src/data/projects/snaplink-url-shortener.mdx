# SnapLink — High-Performance URL Shortener

## Overview

SnapLink is an enterprise-grade, high-performance URL shortening and link management service. Engineered with a focus on ultra-low latency, strict RFC compliance, and zero-bloat infrastructure, SnapLink processes high-throughput redirect requests with an average response time of under 50ms.

## Key Technical Features

### 1. RFC-Compliant Hashing & Encoding
- **Canonicalization (RFC 3986):** Raw input URLs are standardized (trimmed, protocol-normalized, component-encoded) to guarantee deterministic hashing.
- **Base64URL Digest (RFC 4648 §5):** Uses SHA-256 hashing truncated to 7–10 characters, completely URL-safe without requiring URL escape characters (`+` and `/` replaced with `-` and `_`).

### 2. Idempotent Deduplication
- Duplicate long URLs submitted to the system automatically return existing short keys, avoiding redundant storage allocation and keeping database footprint minimal.

### 3. Ultra-Low Latency Redirection (< 50ms)
- By configuring the short code as a clustered B-Tree Primary Key (`id VARCHAR(10) PRIMARY KEY`), lookups execute with `O(log N)` complexity, yielding sub-50ms HTTP 302 redirects.

### 4. Zero-Bloat Containerized Setup
- Packaged using a multi-stage Docker configuration (`node:22-alpine`) with health checks, allowing fully isolated local execution and effortless Vercel edge deployment.
